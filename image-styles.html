오늘의 순서: 프롬프트 복사 → AI에 붙여넣기 → 이미지 만들기 → 저장 → 카카오톡 공유

  • 프롬프트를 복사하고 AI 입력창에 붙여넣기
  • 같은 소재를 서로 다른 스타일로 만들기

시작 전 준비

  • 수업에서 사용할 이미지 생성 AI에 로그인
  • 카카오톡 로그인 및 수업 채팅방 확인
  • 스마트폰 또는 PC, 인터넷 연결
  • PC 실습은 카카오톡 PC 버전 준비
완성 목표는 이미지 2장 + 카카오톡 공유 1회입니다. 생성이 오래 걸리면 첫 번째 이미지 한 장으로 공유를 먼저 해봅니다.

아래 스타일은 특정 지역의 모든 문화를 대표하지 않습니다. 전통 회화, 포스터, 삽화 등 다양한 표현을 체험하는 예시입니다. AI 화면의 메뉴 이름은 서비스와 기기에 따라 다를 수 있습니다.

10–25분 · 함께 따라 하기

텍스트 복사와 이미지 공유는 서로 달라요

먼저 글을 AI에게 보내고, 나중에 완성된 그림을 카카오톡에 보냅니다.

  1. 아래 프롬프트 카드에서 프롬프트 복사 버튼을 누릅니다.
  2. 사용 중인 AI 화면으로 이동하고 메시지 입력창을 선택합니다.
  3. PC는 Ctrl + V, 스마트폰은 입력창을 길게 누른 후 붙여넣기를 선택합니다.
  4. 글이 들어갔는지 확인한 뒤 전송합니다. 이미지 생성 기능이 별도로 있으면 해당 기능을 선택합니다.
  5. 이미지가 완성될 때까지 기다립니다. 완성되면 크게 열어서 확인합니다.
복사 버튼이 작동하지 않으면 프롬프트 글 상자를 선택하세요. PC는 Ctrl + A → Ctrl + C, 스마트폰은 글을 길게 눌러 전체 선택 → 복사합니다.

강사 시연 문장

“지금은 글을 복사합니다. AI 입력창을 누르고 붙여넣습니다. 전송한 뒤 그림이 나오면 저장합니다. 마지막에는 그 그림을 카카오톡으로 보내겠습니다.”

시연은 1번 한국 민화 카드로 진행하세요. 클릭·선택·붙여넣기 단계를 천천히 한 번씩 보여줍니다.

25–65분 · 이미지 만들기

원하는 스타일을 골라 복사하세요

첫 번째는 한국 스타일, 두 번째는 유럽 또는 미국 스타일을 골라보세요. 한국·유럽·미국 각각 10개씩, 총 30개 중 2개를 선택합니다. 꽃과 작은 찻집을 공통 소재로 삼아 비교해 보세요.

글 상자 내용을 직접 바꾼 뒤 복사할 수도 있습니다. 아래 30장의 샘플은 각 프롬프트로 AI가 생성한 수업용 예시입니다. 작가의 실제 작품과 구별해 주세요. 같은 프롬프트를 사용해도 결과는 매번 달라질 수 있습니다.

작가 이름은 학습용 참고입니다. 색·선·질감의 특징을 함께 제시했습니다. 추상화는 찻집의 형태보다 분위기를 표현합니다. 유럽은 여러 나라를 묶은 지역이며 카드에 나라를 표시했습니다. 30개 중 2개만 골라 실습합니다.

화풍 참고: MoMA 미술 용어 · 메트로폴리탄미술관 한국 미술

이미지 생성 후 추가 요청

“이 그림의 구도는 유지하고 색을 파스텔톤으로 바꿔줘.”

“꽃을 더 크게 보여주고 배경은 단순하게 바꿔줘.”

“디지털 명함에 사용할 수 있도록 오른쪽에 빈 여백을 만들어줘. 글자는 넣지 말아줘.”

자신의 이름·전화번호 등은 이미지 생성 프롬프트에 넣지 않아도 됩니다. 오늘은 그림에 글자를 넣지 않고 스타일에 집중합니다.
75–95분 · 카카오톡으로 보내기

완성된 이미지를 수업 채팅방에 공유해요

PC에서 바로 붙여넣기

  1. 완성된 이미지를 크게 열고 마우스 오른쪽 버튼을 누릅니다.
  2. 이미지 복사 메뉴가 보이면 선택합니다. ‘링크 복사’와 구별하세요.
  3. 카카오톡의 수업 채팅방을 열고 메시지 입력칸을 누릅니다.
  4. Ctrl + V를 누릅니다.
  5. 그림 미리보기가 나타나는지 확인한 뒤 전송을 누릅니다.

이미지 복사 메뉴가 없거나 붙여넣기가 되지 않으면 아래 저장·첨부 방법을 사용합니다.

PC에서 저장 후 첨부

  1. AI 화면의 다운로드·저장 버튼 또는 이미지의 다른 이름으로 저장을 선택합니다.
  2. 저장 위치와 파일 이름을 확인합니다. 예: 다운로드 폴더, 한국_민화.png
  3. 카카오톡 수업 채팅방의 파일 첨부(+ 등) 메뉴를 엽니다.
  4. 저장한 이미지 파일을 선택합니다. 파일을 입력칸으로 끌어놓는 방법도 가능합니다.
  5. 보낼 이미지와 채팅방을 확인하고 전송합니다.

스마트폰에서 사진 보내기

  1. AI에서 완성된 이미지를 열고 다운로드·이미지 저장 기능을 선택합니다. 앱에 따라 이미지를 길게 눌러 저장할 수 있습니다.
  2. 사진 앱 또는 갤러리에서 저장된 이미지를 확인합니다.
  3. 카카오톡 수업 채팅방을 엽니다.
  4. 입력창 옆의 + → 앨범/사진을 선택하고 저장한 그림을 고릅니다.
  5. 미리보기와 채팅방을 확인한 뒤 전송합니다.

스마트폰에서는 이미지 붙여넣기를 지원하지 않을 수 있어 저장 후 사진 첨부로 진행합니다.

이미지와 함께 보낼 한 문장

“제가 만든 한국 민화 스타일 찻집입니다. 따뜻한 색이 마음에 들어요.”

“같은 찻집을 유럽 수채화 스타일로 바꿔봤습니다.”

전송 전 확인: 수업 채팅방이 맞나요? 그림 미리보기가 보이나요? 링크나 프롬프트 글만 들어갔다면 이미지 저장·첨부로 다시 해보세요.

막히면 여기서 확인하세요

상황해결 방법
복사 버튼을 눌러도 안 돼요글 상자를 선택하고 직접 전체 선택·복사합니다.
AI가 글로만 답해요“이 설명으로 이미지를 생성해줘”라고 요청하고 이미지 생성 기능을 확인합니다.
이미지 생성이 오래 걸려요잠시 기다리며 다음 스타일을 고릅니다. 반복 전송은 피하고 생성 상태를 확인합니다.
저장한 사진이 안 보여요PC는 다운로드 폴더, 스마트폰은 사진 앱의 최근 항목을 확인합니다. 필요한 사진 접근 권한도 확인합니다.
카카오톡에 글이나 주소만 붙어요완성된 이미지 파일을 저장한 뒤 사진·파일 첨부로 보냅니다.
생성 횟수를 다 썼어요이미 만든 그림으로 저장·공유를 마무리합니다. 추가 스타일은 프롬프트만 비교해 봅니다.
